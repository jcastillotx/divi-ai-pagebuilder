AI-powered design and content creation for the Divi page builder. Generate layouts, write content, and optimize designs using natural language.

== Description ==

**Divi AI Page Builder** brings the power of artificial intelligence to Elegant Themes' Divi Builder. Create stunning websites faster than ever with AI-assisted design and content generation.

= Key Features =

* **AI Layout Generation** - Describe your page in plain English and let AI create complete layouts with sections, rows, and modules
* **Smart Content Writing** - Generate professional copy for any module including headlines, body text, and CTAs
* **Template Library** - Access 2000+ professionally designed templates with automatic brand customization
* **Design Token System** - Set your brand colors and fonts once, apply them across all templates automatically
* **Design Optimization** - Get intelligent suggestions for improving visual hierarchy and aesthetics
* **SEO Recommendations** - Receive actionable tips for improving search engine visibility

= How It Works =

1. **Set Up Your Brand** - Configure your colors, fonts, and style preferences in the WordPress Customizer
2. **Choose Your Creation** - Select whether you're building a full page or a section
3. **Describe What You Need** - Use natural language to describe your content and layout requirements
4. **Review & Insert** - Preview the AI-generated result with your brand styling and insert into your page

= AI Wizard Flow =

**For Pages:**
- Select page type (Landing, About, Services, Contact, etc.)
- Describe the overall layout and content needs
- Specify any media requirements (images, videos)
- AI selects and customizes the best matching template

**For Sections:**
- Choose section type (Hero, Features, CTA, Testimonials, etc.)
- Optionally generate a background (AI image or design pattern)
- Describe the content for the section
- AI creates a customized section ready to insert

== Installation ==

1. Upload the `divi-ai-pagebuilder` folder to your `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to Settings > Divi AI to configure your API keys
4. Set up your Global Styles in Appearance > Customize > Divi AI Global Styles
5. Start using AI features in the Divi Builder!

== Frequently Asked Questions ==

= Does this plugin require the Divi theme? =

Yes, this plugin requires either the Divi Theme or the standalone Divi Builder plugin (version 4.14 or higher).

= What AI services are supported? =

We support OpenAI (GPT-4) and Anthropic (Claude). You can configure one or both API keys.

= Are my API keys secure? =

Yes, API keys are encrypted before being stored in the database using WordPress salts.

= Can I use my own templates? =

The initial version focuses on our curated template library. Custom template support may be added in future versions.

= Will AI-generated content affect my SEO? =

AI-generated content is designed to be high-quality and SEO-friendly. We recommend reviewing and customizing the content to match your brand voice.
